Ethics · on-device

Data stays on your phone. Examples live in browser memory until you clear or export a JSON file. Nothing is sent to a cloud API for training.

Crowd training is uneven. Different grips, pockets, and phone models change motion readings. A set that works for one group may fail for another — discuss bias before trusting the sound.

Export is opt-in. Sharing a training file is like sharing homework: only do it when the class agrees.
